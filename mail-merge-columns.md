# Outreach tracker columns

Use one row per college/society. Keep the list focused on official university/college UPSC, Civil Services, IAS or public administration clubs/societies.

Recommended status values: `To contact`, `Sent`, `Follow-up`, `Interested`, `Not interested`, `No response`, `Wrong contact`.

For low-effort personalized outreach, keep one variable in the first line (`{{club_name}}`) and use the same website/extension links for everyone.
